В новой версии прошивки VBCores произошли некоторые изменения по функционалу и протоколу обмена. Необходимо доработать VBDrive Wizard в соответствие с обновлениями прошивки.

Документация на протокол обмена: https://github.com/VBCores/VBDrive/blob/main/README.md

# Доработки по VBDrive Wizard:

1. Добавился readonly-регистр device, который имеет значение vbdrive. Необходимо при соединении с приводом читать этот регистр, и если ответ vbdrive, то соединение считать успешным.

2. Регистр model переименован в name и он теперь writable. Нужно сделать возможность редактировать регистр name через поле ввода driveNameLineEdit

3. Теперь по команде CALIBRATE приходит следующий ответ в течение калибровки:
CALIBRATE OK          // ответ на команду
CALIBRATE 1/10 DONE   // процесс выполнения калибровки
CALIBRATE 2/10 DONE
CALIBRATE 3/10 DONE
CALIBRATE 4/10 DONE
CALIBRATE 5/10 DONE
CALIBRATE 6/10 DONE
CALIBRATE 7/10 DONE
CALIBRATE 8/10 DONE
CALIBRATE 9/10 DONE
CALIBRATE 10/10 DONE
CALIBRATE FINISH      // калибровка завершена

В форму mainwindow.ui добавлен прогресс бар CalibProgressBar. При нажатии на кнопку CalibrateBtn в этом прогресс баре должен отображаться прогресс калибровки. По документации на привод процесс калибровки отменить нельзя, а также нельзя отправлять другие команды. Нужно продумать механизм определения зависания системы или обрыва связи.

4. Теперь в регистре firmware_rev хранится номер версии, а не её хэш. При загрузке прошивки из remote repo (DownloadFirmwareRadioButton) нужно сравнивать текущую версию прошивки с прошивкой на удаленном репозитории. Если версии совпадают, или текущая версия более новая, то выдавать предупреждающее сообщение.

5. Если текущая версия прошивки привода старее, чем та, что на удаленном репозитории, то CurFirmwareRevLabel должен окрашиваться в красный. При наведении курсора мышки должен появляться tooltip с информацией о том, что прошивка устарела. Если стоит самая последняя версия прошивки, то CurFirmwareRevLabel цвет шрифта должен быть зеленым, а при наведении курсора мыши появляется тултип "У вас самая последняя версия прошивки". Проверка соединения с удаленным репозиторием должна происходить в фоне. Если подключиться не удалось, то не выдавать ошибок, а просто оставлять CurFirmwareRevLabel черным (такого же цвета, как у всех остальных лейблов в приложении). Оттенки шрифта должны гармонировать с приложением.

6. Изменился протокол взаимодействия в режиме SERVO. В связи с этим произошли существенные доработки в графическом интерфейсе. Нужно сделать следующее:

    6.1. изменились/добавились элементы в ServoControlTypeGroupBox, TransientFormGroupBox, TrajParamsGroupBox и FbGainsGroupBox. Необходимо дать логичные и понятные имена элементам внутри этих group box'ов

    6.2. Логика переключения между stacked widget'ами такая:
        - если выбран ServoPositionRadioBtn, то включаются posTrFormPage и posPage
        - если выбран ServoVelocityRadioBtn, то включаются velTrFormPage и velPage
        - если выбраны ServoTorqueRadioBtn и VoltageRadioButton, то включаются torqTrFormPage, EmptyPage и EmptyPage_2
        - если выбран directRadioButton, directRadioButton_2 и directRadioButton_3, то включается EmptyPage
        - если выбран posFiltRadioButton, то включается PosFilterPage
        - если выбран PosPolyRadioButton, то включается PosPolyPage
        - если выбран VelRampRadioButton, то включается VelRampPage
        - внутри group box'ов есть кнопки с надписью Set. По нажатию на эту кнопку, должна происходить запись соответствующих регистров.

    6.3. Все радиокнопки внутри вкладки ServoTab должны иметь такое же визуальное оформление, как внутри вкладки MitTab

    6.4. Убери смену текста лейбла ServoUserTargetLbl в зависимости от выбора радиокнопок внутри ServoControlTypeGroupBox. Пускай текст ServoUserTargetLbl стоит как Target.

    6.5. Сделай оформление новых груп боксов таким же, как и у всех остальных в проекте. Они не должны выбиваться из общего дизайна, включая отступы.

    6.6. При нажатии на кнопку ServoTriangleStartBtn должна отправляться команда servo_cmd, где в <type> прописывается значение, соответствующее выбранным радиокнопкам в ServoControlTypeGroupBox и TransientFormGroupBox.

    6.6. В команде servo_cmd для Serial есть опциональный аргумент command_idx. Его задавать не нужно. Это же касается передачи по Cyphal в сообщении https://github.com/voltbro/cyphal-types/blob/master/voltbro/foc/Servo.1.0.dsdl

7. В DeviceList первая колонка переименована в Name. Нужно отображать в ней данные из регистра name. Аналогичная ситуация с StatusModelLbl.

8. Добавился регистр rated_max_current. Данные, введенные в CurrentLimDoubleSpinBox, должны записываться в этот регистр при нажатии на кнопку WriteRegBtn. Так как это очень критичный регистр, если его значение изменилось, при записи приложение должно выбавать окно примерно такого содержания "Значение регистра rated_max_current будет изменено. Вы уверены, что хотите перезаписать его?" с ответами Да/Нет/Записать все кроме этого регистра.

9. Реализовать возможность прошивки микроконтроллера при подключении к CAN с помощью https://github.com/VBCores/VBBoot, используя те же кнопки внутри FirmwareGroupBox. Прошивка через VBBoot должна происходить только если активно подключение по CAN. Прошивать нужно только выбранный привод в списке DeviceList.
