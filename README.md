# VBDrive Wizard

VBDriveWizard — настольное GUI-приложение для удобного взаимодействия пользователя с
электроприводами [**VBDrive**](https://github.com/VBCores/VBDrive). Приложение служит для базовой проверки и первичной настройки приводов.

После установки необходимо включить пользователя в группу dialout:
```
sudo usermod -aG dialout $USER
```
